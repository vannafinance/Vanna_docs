The reviewed application declares Next.js `^16.2.3`, React `19.2.0`, Stellar SDK `^14.4.3`, and Freighter API `^6.0.1`. These are repository declarations, not claims about latest upstream releases.

## Run the application

From `mercury-stellar-backend`:

```bash
npm ci
npm run dev
```

Use its `LOCAL_SETUP.md` for environment-specific setup. Basic contract reads use the configured testnet RPC. Mercury history, Privy login, Copilot, and Hubble require their respective configuration. Keep service credentials server-side.

## Encode exact amounts

For direct contract calls, use decimal strings or bigint, not floating-point multiplication by 10^18:

```typescript
import { nativeToScVal } from '@stellar/stellar-sdk';

const oneTokenWad = 1_000_000_000_000_000_000n;
const amountArg = nativeToScVal(oneTokenWad, { type: 'u256' });
const symbolArg = nativeToScVal('XLM', { type: 'symbol' });
```

A token balance is native units. Pool deposit and manager repayment amounts are WAD. Pool redemption expects WAD **receipt quantity**. Controller minima and LP-removal units vary by protocol; see the controller references.
