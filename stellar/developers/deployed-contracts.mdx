## Verify a deployment

Read the Registry's protocol configuration, asset metadata, controller mappings and tracking metadata. Check each pool's underlying and receipt, origination fee, pause flags and rate coefficients, and AccountManager's live execution gate. Compare the deployed WASM with the Rust source before assuming they match.
