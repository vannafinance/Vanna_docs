## Verify

Read `ProtocolConfig`, each `AssetConfig` and `Reserve`, the oracle's `PriceBook`, and a known margin PDA. Compare the deployed program data against the SHA-256 hashes in `deployments/hosted-fork.json`. A reset fork is a new world: user margin addresses derive from the wallet, not from a constant table.
