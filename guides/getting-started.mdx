Vanna's Stellar testnet application lets you supply liquidity, manage a margin account, swap assets, and explore external yield strategies using test tokens.

## Connect and fund

Open the testnet app using **Launch App**. Connect Freighter, or use the email/Google option when Privy login is enabled. The build targets Stellar testnet. Claim test assets through the Faucet and retain XLM for fees and account reserves.

The four lending assets are **XLM, BLUSDC, AqUSDC, and SoUSDC**. The USDC variants are distinct test tokens; choose the one required by the pool or protocol.

## Choose a flow

| Goal | Start here |
|---|---|
| Supply wallet assets for lending yield | [Earn](/guides/earn/overview) |
| Deposit collateral and borrow | [Margin](/guides/margin/overview) |
| Swap tokens | [Spot](/guides/trade/spot-swap) |
| Supply to Blend or provide AMM liquidity | [Farm](/guides/farm/overview) |
| Use a simplified strategy workflow | [Lite Mode](/guides/farm/leveraged-yield) |
| See combined holdings | [Portfolio](/guides/portfolio) |
| Build and review an assisted action plan | [Copilot](/guides/copilot) |

Pro is the default mode. Switch back to Pro to access advanced screens hidden in Lite. Perps and options are not enabled in this Stellar build.

A successful request or wallet signature is not final confirmation. Wait for the transaction result and refreshed balances before the next dependent step.
