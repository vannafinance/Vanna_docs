## Supported connection methods

The current build supports **Freighter** and, when configured, **Privy email/Google login with an embedded Stellar wallet**. The presence of other Stellar wallets does not mean they have a connector in this application.

## Connect

1. Open the Stellar testnet application and choose **Connect Wallet**.
2. Select Freighter and authorize access, or select the enabled email/Google option and complete login.
3. Check the displayed wallet address. For Freighter, use the testnet network when signing this application's transactions.
4. Wait for the account and balance reads to complete. Existing margin accounts are rediscovered from chain.

The application is configured for testnet; changing a wallet setting does not turn this build into a mainnet application.

## Faucet and balances

Open **Faucet**, choose the asset required by your intended market, and complete its funding or mint flow. XLM funding and issued-token mint/trustline flows can differ; do not assume each faucet action has the same number of signatures.

BLUSDC is for Blend, AqUSDC for Aquarius, and SoUSDC for Soroswap. Token identity is determined by its address/issuer, not just the word USDC. Keep XLM available for network fees and reserves. Receiving classic issued assets may require a trustline.

## Reconnect

Use the same wallet or Privy login to return to the same account. A different address has different holdings. Copilot delegated signing, when offered, requires a separate user consent step; connecting alone does not authorize every future action.
